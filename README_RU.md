# Freaky Tiers — инструкция

## Что внутри
Публичный сайт в тёмном Minecraft PvP стиле: рейтинг игроков, тиры LT5–HT1, фильтры, поиск, напарники и автообновление каждые 30 секунд. Защищённый API принимает данные от Discord-бота.

## 1. Загрузить на GitHub
Создай репозиторий на https://github.com/new с именем `FreakyTiersSite`, затем загрузи в него содержимое архива. `app.py`, `requirements.txt`, `render.yaml`, `templates/` и `static/` должны быть в корне репозитория. Не загружай токен Discord или секреты.

## 2. Публикация на Render
1. Открой https://render.com/ и войди через GitHub.
2. Создай новый Blueprint и выбери репозиторий.
3. Render прочитает `render.yaml` и создаст сайт.
4. После deploy открой публичный адрес сервиса, например `https://freaky-tiers-site.onrender.com`.

Важное замечание: `render.yaml` использует persistent disk для SQLite. Если выбранный план не поддерживает диск, выбери поддерживаемый план или подключи постоянную базу данных, иначе сохранность рейтингов не гарантируется.

## 3. Настроить синхронизацию
1. В Render → Web Service → Environment найди `SITE_SYNC_SECRET`, сгенерированный для сайта. Сохрани его в безопасном месте.
2. В папке Discord-бота выполни `py -m pip install requests`.
3. Открой `bot_sync_snippet.py.txt`, добавь его код в `bot.py` после импортов.
4. В `/setrank` и `/setteamrank` найди места, где обновляются и сохраняются `ranks_data` и `teams_data`. Сразу после сохранения обоих актуальных словарей добавь `sync_rankings_to_website(ranks_data, teams_data)`. Имена переменных могут отличаться — используй имена из своего файла.
5. В PowerShell перед запуском бота задай переменные (подставь настоящий URL и секрет):

   `$env:WEBSITE_SYNC_URL="https://ТВОЙ-САЙТ.onrender.com"`

   `$env:WEBSITE_SYNC_SECRET="СЕКРЕТ-ИЗ-RENDER"`

   `py bot.py`

Не отправляй `SITE_SYNC_SECRET` или `DISCORD_TOKEN` в чат и не вставляй их в публичный код.

## 4. Работа 24/7
Если бот запускается на твоём ПК, синхронизация работает, только когда бот запущен. Чтобы бот работал постоянно, разверни его как отдельный Background Worker и задай там `DISCORD_TOKEN`, `WEBSITE_SYNC_URL` и `WEBSITE_SYNC_SECRET`. Токен Discord нужен только боту, не сайту.

## 5. Проверка
После запуска бота выполни `/setrank` для тестового игрока и обнови сайт. Сайт опрашивает API каждые 30 секунд.

## Формат данных
Сайт ожидает `ranks` как объект ID → данные игрока (`name` и `rank`/`tier`), а `teams` — объект ID → имя или объект с `teammate`/`teammate_name`. Если структура JSON в текущем боте другая, потребуется адаптировать `static/app.js` или преобразовать данные перед отправкой. Для точного подключения понадобится увидеть структуру JSON без токенов и секретов.
